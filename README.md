# ok-online judge

기존 세종대학교 Online Judge에서는 코드를 제출한 뒤 수정하고 다시 제출하려면 여러 탭과 화면을 오가야 합니다. 이 불편을 줄이기 위해 문제 확인, 코드 편집, 실행, 제출과 결과 확인을 한 화면에서 할 수 있는 Chrome 확장 프로그램을 개발했습니다.

**세종대학교의 공식 프로그램이 아닙니다. 시험에서는 사용하지 마세요.**

## 설치

1. [릴리스](https://github.com/okjaeho/ok-online-judge/releases)에서 설치용 ZIP을 받아 압축을 풀고 보관할 위치에 둡니다.
2. `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `extension` 폴더를 선택합니다.
4. [EX-OJ](https://ex-oj.sejong.ac.kr/index.php/auth/login/)에 로그인하고 페이지를 새로고침합니다.
5. 오른쪽 아래 **ok-online judge** 버튼이나 Chrome의 확장 아이콘을 누릅니다.

설치 후에도 `extension` 폴더를 보관해주세요.

## 사용

강좌와 탭을 선택한 뒤 문제를 열어 코드를 작성합니다. **Run**은 직접 입력한 데이터로 C/C++/Python을 브라우저에서 실행하고, **Sample Submit / Submit**은 학교 OJ에 제출합니다. 코드는 문제·언어별로 자동 저장됩니다.

문제와 코드 사이 손잡이로 비율을 조절하거나 문제를 접을 수 있습니다. **교재**에서 PDF를 불러오면 강좌별로 보관되며 다음에 다시 열 때도 유지됩니다. 교재 페이지 번호는 위의 페이지 칸에서 지정하면 저장됩니다.

Run의 C/C++은 WebAssembly용 Clang 22를, Python은 CPython 3.13.2를 사용합니다. 학교의 GCC·Python과 실행 환경에 차이가 있으므로 구형 GCC에서만 지원하는 코드는 **Sample Submit**으로 확인해주세요. Run 결과는 학교 채점 결과에 반영되지 않습니다.

세종대학교의 공식 프로그램이 아닌 개인 제작 도구입니다. 사용으로 발생한 문제에 대해 제작자는 책임을 지지 않습니다.
